웹에서 요소란? 태그를 뜻함.
요소를 제어한다는건 위치 이동 속성값을 바꾸는 행위들
자바스크립트는 태그를 제어한다.

스크립트는 바디의 제일하단에 작성한다.
alert - 확인을 위한 알림창
confirm - 확인창인데 ture, false 로 하는거
prompt - 입력가능한 알림창

선언을 제일위로 끌어올리는건 hoisting 밑에 선언해도 변수를 쓸수있는데 var가 호이스팅 재선언이 되어 사용을 잘안한다.
let (호이스팅-밑에서 쓴거 위에서 쓰는거 재선언이 안된다)을 많이쓰고 상수는 const 사용

이벤트
이벤트 앞에는 on을 넣는다.

마우스이벤트
click, dbclick(더블클릭), mousedown,move,over(hover느낌),out, up

키보트이벤트 - down, up, press
키보드 keypress 와 마우스의 click 비슷한의미

로딩이벤트
abort - 문서 로딩전에 불러오기(다운로드)를 멈췄다 
error - 문서가 로딩이 정확히 안되면
load - 문서 로딩끝나면
resize - 크기바뀔때
scrol - 화면 스크롤
unload - 문서에서 벗어날때 

form 이벤트 - 입력,클릭할수있는대상을 form (input, checkbox 등)
blur - 폼에서 포커스 벗어나면 (회원가입일때 포커스 벗어나면 바로 뜨는거)
change - input 안에 값이 변하면 (목록이나 체크상태가 변경되면)
focus - blur 반대, 포커스가 들어가면
reset - 폼이 리셋되면
submit - 전송(submit) 버튼을 클릭했을떄

이벤트처리기(이벤트핸들러)
이벤트가 발생했을때 처리하는 함수 

객체 - 프로퍼티(객체의 특징이나 속성)와 메서드(동작)를 가진다

window 안에 document, navigator,history, location,screen
document - body영역안에 만드는 문서정보
navigator - 브라우저의 정도가 들어있다 - geolaction(위치정보)
history - 방문기록 이동 여부 확인
location - url 정보가 있는것 많이쓰는건 href,pathname,search(리액트에도 나온다)
href(전체 URL) - 사용하면 페이지 이동(주소값을 지정된 주소값으로 바꾸어라)
replace 함수 - history남기지 않고 페이지 이동(뒤로가기안됨)

id는 유일(단수사용)
태그네임은 복수형으로 가져온다.

querySelector 첫번쨰한개만가져오면 여러개면 querySelectorAll / querySelector뒤에는 선택자가 사용된다.
